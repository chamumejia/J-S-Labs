# J&S-Labs

J&S-Labs desarrolla soluciones de software para automatizar tareas y simplificar procesos.
Nuestro objetivo es crear herramientas que hagan el trabajo más ágil, organizado y fácil.

## Equipo

| Integrante | Usuario de GitHub | Rol |
|---|---|---|
| Samuel | `chamumejia` | Líder del equipo; coordina el trabajo y revisa los cambios del proyecto. |
| Jacob | `Jacob-hast` | Responsable de la documentación y colaborador del desarrollo. |

## Organización del repositorio

- `README.md`: presenta J&S-Labs, al equipo y la organización del proyecto.
- `CONTRIBUTING.md`: contiene las reglas para ramas, commits, Pull Requests y revisión de cambios.
- `src/`: espacio destinado al código fuente de la aplicación.
- `tests/`: espacio destinado a las pruebas del proyecto.

Los documentos principales se mantienen en la raíz del repositorio. El código y las pruebas se organizan por separado para que sea más fácil encontrarlos y mantenerlos.

## Contribuciones

El equipo trabaja en ramas separadas y propone sus cambios mediante Pull Requests hacia `main`. Samuel, como líder, coordina el proceso de revisión. Jacob y Samuel revisan mutuamente los cambios, y quien crea un Pull Request no aprueba su propio trabajo. Antes de integrar un cambio, debe contar con la aprobación del otro integrante y cumplir las reglas de `CONTRIBUTING.md`.
